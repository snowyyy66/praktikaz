                            # WIWANG Marketplace 🛒

                            Современный прототип маркетплейса б/у вещей (аналог Авито/Авто.ру), разработанный в рамках учебной практики по программированию. 
                            Дизайн проекта адаптирован из премиального игрового интерфейса под нужды реальных пользователей.

                            ## О проекте
                            Проект разбит на две независимые части: **Frontend** (Клиентская часть) и **Backend** (Серверная часть). Это позволяет обеспечить гибкость, безопасность и лучшую масштабируемость платформы. 

                            ### Основной функционал
                            - Удобная навигация по реальным категориям: Транспорт, Недвижимость, Предметы, Одежда и аксессуары, Услуги, Аренда.
                            - Детальная карточка одежды/предметов: просмотр характеристик, графиков и информации о продавце.
                            - Детальная карточка транспорта: просмотр галереи, технических характеристик мощностей (двигатель, пробег, трансмиссия).
                            - Современный тёмный премиум-дизайн с плавными анимациями без использования тяжелых сторонних UI-библиотек.

                            ## Технологический стек
                            - **Frontend**: React 18, Vite, Vanilla CSS.
                            - **Backend**: Node.js, Express (Прототип API).
                            - **Архитектура**: REST API, строгая компонентная структура.

                            ## Запуск проекта

                            ### 1. Запуск Backend-сервера
                            В первой вкладке терминала:
                            ```bash
                            cd backend
                            npm install
                            npm run dev
                            ```

                            ### 2. Запуск Frontend-приложения
                            Во второй вкладке терминала:
                            ```bash
                            cd frontend
                            npm install
                            npm run dev
                            ```

                            Приложение будет доступно по адресу: http://localhost:5173

                            ## Структура репозитория
