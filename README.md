# WIWANG Marketplace

Веб-приложение маркетплейса для размещения и покупки товаров. Пользователи могут искать объявления, общаться с продавцами и оформлять заказы. Для части товаров предусмотрен формат аукциона.

## Возможности

- Каталог объявлений с поиском, фильтрами и категориями
- Карточки товаров и профили продавцов
- Регистрация и вход пользователей
- Создание и управление собственными объявлениями
- Избранное, заказы, сообщения и уведомления
- Фиксированная цена и ставки на аукционах
- Панель администратора
- Загрузка изображений товаров

## Технологии

| Область | Стек |
|---|---|
| Frontend | React 18, Vite 5, React Router, JavaScript, CSS |
| Backend | Node.js, Express 4, REST API |
| Хранение данных | SQLite через sql.js |
| Дополнительно | Multer для загрузки изображений, bcrypt для хеширования паролей |

## Запуск локально

Нужен установленный Node.js и npm.

### 1. Backend

```bash
cd backend
npm install
npm run dev
```

### 2. Frontend

В отдельном терминале из корня проекта:

```bash
cd frontend
npm install
npm run dev
```

Frontend запускается на адресе, который покажет Vite (обычно `http://localhost:5173`). Backend API доступен на `http://localhost:3000/api`.

## Запуск обеих частей

Чтобы запускать обе части одной командой, сначала установите зависимости в обеих папках и в корне:

```bash
cd backend && npm install
cd ../frontend && npm install
cd .. && npm install
npm run dev
```

## Разработка

Сборка frontend:

```bash
cd frontend
npm run build
```

Проверка стиля frontend:

```bash
cd frontend
npm run lint
```
