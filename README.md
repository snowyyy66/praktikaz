# WIWANG Marketplace 🛒

Премиальный прототип маркетплейса товаров и услуг, вдохновленный дизайном современных игровых интерфейсов и экосистемой Apple. Проект демонстрирует полноценный цикл взаимодействия пользователя с платформой: от поиска и аукционов до бронирования услуг и обмена сообщениями.

## ✨ Ключевые особенности

*   **🛒 Разнообразные категории**: Поддержка специфической логики для Транспорта, Недвижимости, Услуг и обычных товаров.
*   **🔨 Система аукционов**: Реализованная логика торгов в реальном времени с минимальным шагом ставки и обратным отсчетом.
*   **📅 Бронирование услуг**: Выбор доступных временных слотов для записи к специалистам или аренды.
*   **💬 Центр сообщений**: Полноценная система чатов между покупателями и продавцами.
*   **⭐ Система отзывов**: Возможность оставлять развернутые отзывы с прикреплением медиафайлов (фото/видео).
*   **🛡️ Админ-панель**: Инструменты для модерации объявлений и управления контентом.
*   **🔔 Уведомления**: Оповещения о новых ставках, продажах и сообщениях.
*   **📊 Аналитика**: Уникальные просмотры, лайки и статистика продавца.

## 🛠 Технологический стек

### Frontend
- **React 18** + **Vite**: Быстрая сборка и современный подход к рендерингу.
- **Vanilla CSS**: Кастомная стилизация без тяжелых фреймворков для достижения максимальной плавности анимаций.
- **Context API**: Управление состоянием приложения (авторизация, корзина, уведомления).

### Backend
- **ASP.NET Core (.NET 8/9)**: Высокопроизводительный серверный движок на C#.
- **Dapper**: Легковесный ORM для максимально быстрых SQL-запросов.
- **SQLite**: Портативная и надежная база данных.
- **Swagger**: Документированное API для удобной интеграции.

## 🚀 Запуск проекта

### Предварительные требования
- Node.js (v18+)
- .NET SDK (8.0 или 9.0)

### 1. Быстрый запуск (рекомендуется)
В корневой директории проекта выполните:
```bash
npm install
npm run dev
```
Это запустит одновременно и Backend (порт 3000), и Frontend (порт 5173) с помощью `concurrently`.

### 2. Ручной запуск компонентов

**Backend:**
```bash
cd backend
dotnet run
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```
