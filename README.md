# WIWANG Marketplace

Прототип маркетплейса товаров и услуг на базе ASP.NET Core 10 и React 18. Проект демонстрирует полный цикл работы платформы: от динамических аукционов до многослойной системы отзывов и чатов.

---

## Концепция и дизайн

Проект вдохновлен минимализмом Apple и функциональностью интерфейсов AAA-игр. Основной упор сделан на:
- **Плавность**: Использование Vanilla CSS для контроля каждой микро-анимации.
- **Интуитивность**: Категории (Транспорт, Недвижимость, Услуги) имеют уникальную логику отображения и взаимодействия.
- **Премиальность**: Отсутствие шаблонных решений, кастомные UI-компоненты.

## Технологический стек

### Backend

- **Framework**: ASP.NET Core 10 (Web API)
- **Data Access**:
  - **Entity Framework Core 10**: Основная ORM для сложных связей и миграций.
  - **Dapper**: Для высокопроизводительных выборок в критических узлах (например, поиск товаров).
- **Database**: SQLite (Shared Cache mode)
- **Security**: BCrypt.Net для хеширования паролей.
- **API Docs**: Scalar (современная альтернатива Swagger для интерактивного тестирования).

### Frontend

- **Runtime**: React 18 + Vite 5.
- **Routing**: React Router DOM v6.
- **Styling**: Vanilla CSS с использованием CSS-переменных (Design Tokens).
- **Icons**: Lucide React.
- **State Management**: React useState/useEffect + localStorage для авторизации и системы уведомлений.

## Архитектура проекта

Приложение следует классической многослойной архитектуре (N-Tier Architecture), обеспечивающей разделение ответственности:

1. **Presentation Layer**: REST Controllers в ASP.NET Core. Обрабатывают HTTP-запросы и возвращают DTO (Data Transfer Objects).
2. **Service Layer (Business Logic)**: Инкапсулирует правила предметной области. Сервисы (IProductService, IAuctionService и др.) координируют работу между репозиториями.
3. **Repository Layer**: Абстракция над доступом к данным. Позволяет легко переключаться между EF Core и Dapper или менять БД.
4. **Data Layer**: EF Core DbContext и конфигурация сущностей.

## Основные функциональные модули

### Система аукционов

Реализована логика торгов в реальном времени:
- Автоматическая проверка минимального шага ставки.
- Контроль даты окончания торгов.
- История ставок для каждого лота.

### Центр коммуникаций

Полноценная система личных сообщений:
- Группировка сообщений по диалогам (Conversations).
- Уведомления о новых сообщениях в реальном времени (через фронтенд-пуллинг).

### Продвинутые отзывы

Гибридная система отзывов:
- Отзывы о продавце (рейтинг пользователя).
- Отзывы о конкретном товаре.
- Поддержка медиа-контента (фото/видео).

### Категорийная логика

Система адаптируется под тип товара:
- **Недвижимость**: Запись на просмотр.
- **Услуги**: Выбор временного слота (Booking).
- **Товары**: Стандартная корзина и покупка.

## Запуск проекта

### Предварительные требования

- **.NET SDK 10.0+**
- **Node.js v18+**

### Быстрый старт (одновременный запуск)

Из корня проекта:
```bash
npm install
cd frontend
npm install
cd ..
npm run dev
```

Frontend запустится на http://localhost:5173, Backend -- на http://localhost:3000.

### Ручной запуск

**Backend:**
```bash
cd backend
dotnet run
```
API Reference (Scalar) будет доступен по адресу: http://localhost:3000/scalar/v1.

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

## Структура папок

```text
praktika/
  frontend/                 # React-приложение
    src/
      api.js                # Конфигурация API (fetch wrapper)
      components/           # UI-компоненты (Header, Sidebar)
      pages/                # Основные экраны приложения
  backend/                  # ASP.NET Core приложение
    Controllers/            # API-эндпоинты
    Data/                   # DbContext и Seed-данные
    Migrations/             # История изменений БД
    Models/                 # Сущности (Entities) и DTO
    Repositories/           # Слой доступа к данным
    Services/               # Бизнес-логика
    Middleware/              # Обработка ошибок и логирование
    uploads/                # Хранилище загруженных изображений и видео
    marketplace.db          # База данных SQLite
  backend.Tests/            # Юнит-тесты (xUnit)
```
